무료 오프라인 영어 음원 스크립트 앱의 첫 배포입니다.

- Windows 10/11 64비트 지원
- MP3 여러 개 변환, 스크립트 편집과 자동 저장
- 완료된 파일을 유지하며 중단·이어서 작업
- Word(.docx)·텍스트(.txt) 저장
- 기본 영어 모델 base.en 포함

첨부된 `ScriptStudio-Windows.zip`을 모두 풀고 `ScriptStudio.exe`를 실행하세요.
기본 모델로 변환할 때 인터넷이나 API 키가 필요하지 않습니다.
압축 파일은 약 138MB이며, 압축 해제 후 약 160MB입니다.

필요 환경: .NET Framework 4.8 및 Microsoft Visual C++ x64 실행 구성 요소.
설치 안내와 자세한 사용법은 ZIP 안의 `사용안내.txt`에 있습니다.

이 배포에는 사용자 음원, 변환된 스크립트, 작업 이력을 포함하지 않았습니다.
