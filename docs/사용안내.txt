Script Studio
영어 음원 스크립트 앱 · Windows 10 / 11 64비트

시작하기

1. 압축 파일을 폴더에 모두 풉니다.
2. 폴더 안의 ScriptStudio.exe를 실행합니다.
3. '파일 추가'나 '폴더 추가'를 누르거나 MP3 파일을 창에 끌어놓습니다.
4. 변환할 파일 왼쪽의 체크 상자를 선택합니다.
5. '선택 파일 변환'을 누릅니다.
6. 파일 이름을 누르면 오른쪽에서 스크립트를 확인하고 수정할 수 있습니다.
7. 저장할 파일을 체크한 뒤 '선택 스크립트 Word 저장' 또는 '텍스트 저장'을 누릅니다.

Word 파일은 .docx 형식입니다. 여러 파일을 저장하면 파일 이름 순서대로 묶고,
각 파일의 스크립트를 새 페이지에서 시작합니다. Word가 설치되어 있지 않아도
이 앱에서 .docx 파일을 만들 수 있습니다.

모델과 인터넷 연결

기본 영어 전용 base.en 모델이 포함되어 있으므로 바로 사용할 수 있습니다.
기본 모델 크기는 약 148MB이며 실행 도구가 추가로 필요합니다.
앱 폴더 전체는 약 170MB 안팎입니다.

기본             base.en    모델 약 150MB
정확도 우선      small.en   모델 약 490MB (선택 다운로드)
빠른 초안        tiny.en    모델 약 80MB  (선택 다운로드)

모델을 바꾸려면 위쪽 목록에서 선택한 뒤 '선택 모델 내려받기'를 누르세요.
추가 모델을 내려받을 때만 인터넷이 필요합니다. 다운로드 중에는 중단할 수 있으며,
미완성 모델 파일은 삭제됩니다. 다운로드를 다시 누르면 처음부터 받습니다.
기존 모델은 그대로 보관합니다.

음원 변환은 CPU로 이 PC 안에서 실행됩니다. 유료 API, 회원 가입, API 키가
필요하지 않습니다. 음원과 스크립트를 외부 서버에 업로드하지 않습니다.

지원 파일

MP3, WAV, FLAC, OGG를 지원합니다. 폴더 추가는 해당 폴더의 파일만 가져옵니다.
Day1, Day2, Day10처럼 숫자가 있는 파일 이름은 숫자 순서로 정렬합니다.
같은 경로의 파일을 중복으로 추가하면 하나만 목록에 남깁니다.

자동 저장과 이어서 작업하기

완료된 스크립트와 편집 내용, 파일 목록은 앱 폴더의 data 폴더에 자동 저장합니다.
앱을 닫았다가 열면 이전 작업을 불러옵니다.
'중단'을 누르면 현재 파일을 중단하고, 완료된 파일은 그대로 보존합니다.
다시 '선택 파일 변환'을 누르면 완료된 파일을 건너뛰고 남은 파일을 처리합니다.
실패한 파일은 오류 상태로 표시하며, 해당 파일을 선택하면 안내가 보입니다.

완료된 파일을 다시 인식하려면 파일 이름을 선택한 뒤 '이 파일 다시 변환'을 누르세요.
변환에 성공하면 이전에 편집한 스크립트를 새 결과로 바꾸므로 주의하세요.
진행 중인 파일은 결과가 바뀌지 않도록 편집할 수 없습니다.
원본을 다른 프로그램으로 재생하면서 인식 내용을 확인할 수 있습니다.

'선택 항목 빼기'는 목록에서 강조된 항목을 뺍니다. 원본 MP3는 삭제하지 않습니다.
완료된 스크립트 원문은 data/results 폴더의 텍스트 파일에도 남아 있습니다.
다른 PC로 옮길 때는 exe 파일만 옮기지 말고 앱 폴더 전체를 옮기세요.
원본 음원 경로가 바뀌면 목록에서 예전 항목을 빼고 새 위치의 파일을 추가하세요.

확인할 점

정확도와 속도는 녹음 상태와 PC 성능에 따라 달라집니다.
고유명사, 숫자, 잡음이 있는 부분은 원본을 들으며 확인하세요.
저장 위치는 본인이 쓸 수 있는 문서 폴더 등을 선택하세요.
앱 폴더의 runtime, models, data 폴더는 각각 실행 도구, 모델, 작업 내용을 담습니다.
기존 작업을 보존하려면 data 폴더를 함께 백업하세요.

다른 PC에서 음성 인식 도구가 시작되지 않는 경우

Microsoft Visual C++ x64 실행 구성 요소가 필요합니다. 이 구성 요소가 없는 PC에서는
앱이 안내 메시지를 표시합니다. Microsoft 공식 설치 파일로 설치한 뒤 다시 실행하세요.
이미 설치되어 있어도 오래된 버전이면 최신 버전으로 업데이트가 필요할 수 있습니다.
설치는 해당 PC에서 한 번만 필요하며 변환 요금과는 관계가 없습니다.
공식 설치 파일: https://aka.ms/vc14/vc_redist.x64.exe
공식 안내: https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist
